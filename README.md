## Sobre mim

Olá! Sou **Marlon Lara**, desenvolvedor de software e designer, apaixonado por tecnologia e pela criação de soluções digitais que unem funcionalidade, desempenho e experiência do usuário.

Tenho experiência em diferentes etapas do desenvolvimento de software, desde o planejamento e a criação de interfaces até a implementação de aplicações, APIs e integração com bancos de dados.

Atualmente, venho aprofundando meus conhecimentos em **desenvolvimento backend**, utilizando **Node.js, Express, Java e Spring Boot** para construir APIs REST, implementar autenticação JWT e integrar aplicações com bancos de dados relacionais como PostgreSQL e MySQL.

Além disso, possuo experiência com **desenvolvimento mobile em Flutter**, desenvolvimento web e **UI/UX Design**, trabalhando na criação de interfaces, protótipos e identidades visuais. Gosto de compreender o funcionamento de um produto como um todo, conectando design, experiência do usuário e desenvolvimento.

**Formação:** Técnico em Desenvolvimento de Sistemas — Firjan SENAI SESI Petrópolis.

## Áreas de atuação

**Desenvolvimento Backend:** Construção de APIs REST utilizando Node.js, Express e Spring Boot, com implementação de autenticação JWT, armazenamento seguro de senhas, modelagem de dados e integração com bancos relacionais. Também trabalho com documentação e testes de endpoints utilizando Swagger e Postman.

**Desenvolvimento Mobile:** Criação de aplicativos com Flutter e Dart, incluindo desenvolvimento de interfaces, gerenciamento de estados, consumo de APIs e integração entre aplicações mobile e serviços backend.

**Desenvolvimento Web:** Desenvolvimento de interfaces e aplicações web utilizando HTML, CSS e JavaScript, com atenção à estruturação de páginas, responsividade, interatividade e usabilidade.

**Design & UI/UX:** Criação de identidades visuais, interfaces digitais, protótipos e materiais gráficos. Utilizo ferramentas como Figma e Adobe Creative Cloud para desenvolver projetos que combinam estética, organização visual e experiência do usuário.
